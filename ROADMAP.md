# Roadmap

## Now

- [x] Desktop app (macOS)
- [x] Browser verifier (check.html)
- [x] Proof chaining
- [x] Key delegation
- [x] RFC 3161 external timestamps
- [x] Full chain walk verification
- [x] Public release with downloads

## Next

- [ ] Host browser verifier on a public URL (GitHub Pages or similar)
- [ ] Windows build (.msi / .exe)
- [ ] Linux build (.AppImage / .deb)
- [ ] macOS code signing + notarization
- [ ] "Reveal proof in folder" button after creation
- [ ] Copy share message action in UI

## Later

- [ ] Bundled format (.win) — file + proof in one portable package
- [ ] Batch verification (multiple files at once)
- [ ] Proof chain visualization in UI
- [ ] CI pipeline for automated release builds
- [ ] Independent security audit

## Not planned

- Accounts or user registration
- Cloud storage or server-side verification
- Blockchain integration
- Subscription or payment model
